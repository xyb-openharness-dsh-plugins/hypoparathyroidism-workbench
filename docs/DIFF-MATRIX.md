## 差异化矩阵（场景 → 功能 → 怎么验收）
1. 场景：患者每次化验后要同时看钙、磷、PTH 三张报告 → 功能：钙-磷-PTH 三联指标组，同组同屏、同一可比组 → 验收：MT03 两页目录一致；三指标分进同一类别块，不混入平铺容器。
2. 场景：补钙补 D 加减量后尿钙跟着变 → 功能：剂量变更链与尿钙化验点同时间轴 → 验收：折入折叠卡（32 号），剂量事件可检索到相邻尿钙点，无判定词。
3. 场景：夜间手足搐搦 → 功能：发作—缓解事件泳道（小时级轨道仅此用）→ 验收：事件类型仅「用药/就诊/检查/缓解开始/加重」；急性求助只引用医生行动计划原文，阈值【待核】。
4. 场景：怕长期补 D 伤肾 → 功能：并发症筛查节奏页（尿钙/肾功能/骨密度/眼科/颅脑影像）→ 验收：只存检查事实与日期，无风险评分列（Q38）。
