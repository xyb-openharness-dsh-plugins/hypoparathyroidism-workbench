## 一级重名率实测
- 逐字同名（与任一基准）：看板、病情整理、病情一图秀、心理与家庭、临床试验、资料与复诊 = 6/10
- 部分/改词：化验与指标（~检查与指标）、筛查与随访（~复诊准备）= 2/10
- **一级重名率 = 同名 6/10 = 60% ≤ 70% ✓**（改词 2 项不计入同名）
- 差异化独有页：发作与缓解、用药滴定（语义重写）——病种独有信息维度，非换名复用。

## 二级页差异（防换名复用关键 3 条）
1. labs 下「钙-磷-PTH 三联组」：三指标同组同屏、同可比组规则（家族任何仓无电解质三元组）。
2. meds 下「剂量变更链」：更正=新增版本 + 与尿钙化验点同时间轴（cervical 治疗历程是分期线序，本台无线序）。
3. events 下「发作泳道」：小时级轨道仅用于发作事件（用药/就诊/检查/缓解开始/加重五类），急性求助卡只引用医生行动计划原文。
