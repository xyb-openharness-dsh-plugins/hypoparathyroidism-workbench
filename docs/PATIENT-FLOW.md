## 旅程五段
1. 确诊期：反复口周麻木/手足搐搦就诊 → 血钙低+血磷高+PTH 低 → 住院排查 → 基因检测（CaSR/GCM2 等待核列表）确诊。痛点：罕见、易误诊（误当癫痫/焦虑治疗）。
2. 滴定期：出院后钙剂+活性维生素 D 起始剂量 → 每 2–4 周调药 → 化验频繁。痛点：不知道加量后为什么又查尿钙。
3. 稳定期：每 3–6 个月化验一次 → 指标记住自己"正常值"的窗口。痛点：换医院/换医生要重新解释病情。
4. 发作期：漏服、腹泻、感染诱发急性低钙 → 口周麻木/手足搐搦 → 急诊静脉补钙。痛点：说不清病史，急诊接待医生不熟。
5. 随访期：年度并发症筛查（尿钙/肾功能/骨密度/眼科/颅脑）→ 与生育遗传咨询。痛点：不知道该多久查一次、查什么。

## 每段对功能线的挂接（M1 SCENARIOS 展开为可验收场景）
确诊期→档案页；滴定期→用药滴定+尿钙同轴；稳定期→三联指标卡+一图秀；发作期→事件泳道+急救卡；随访期→筛查节奏页+复诊材料。
