# SPEC · 遗传性甲状旁腺功能减退症工作台（小钙宝 CalPal，品牌占位）

- 版本：v0.1.0-draft · 2026-11-14 · 病种：遗传性甲状旁腺功能减退症（罕见病 #34，《86 个罕见病病种诊疗指南（2025 年版）》目录 189）
- 定位：本机优先的患者信息整理与就诊准备工具；只整理不解读，不做诊断与治疗建议。
- 产品线：非肿瘤慢病线（无分期、无治疗线序、无疗效应答语义）。

## 一、服务对象与病程覆盖
- 服务主体：患者本人 + 家属照护者（可切换视角，默认患者视角）。
- 病程覆盖：确诊后全病程——确诊依据建档 → 长期钙剂/活性维生素 D 滴定 → 周期性化验 → 急性低钙发作 → 并发症筛查 → 复诊准备。
- 默认无出生缺陷谱系与新生儿期记录（R2 非儿童线；如需家长代记见 USER-RESEARCH 待决）。

## 二、一级导航（草案，M1 经 DIFF-MATRIX 实测后定稿）
1. #dashboard 看板：两套合成档案、最近化验、最近发作、待办筛查
2. #record 病情整理五 Tab：来源 → 核对 → 档案 → 分类指标 → 汇总
3. #metrics 化验指标：钙-磷-PTH 三联组、25(OH)D、尿钙/肌酐、肾功能、骨密度（分组独立）
4. #one-chart 一图秀：指标时间曲线（同指标可比组内连线）
5. #meds 用药滴定：钙剂/活性维生素 D 剂量变更链（更正=新增版本）
6. #events 发作与缓解：急性低钙发作—缓解事件泳道（日期/症状/持续时间/处置原文）
7. #followups 筛查与随访：尿钙、肾功能、骨密度、眼科（白内障）、颅脑影像（基底节钙化）节奏
8. #documents 报告与原件：化验单、出院小结、基因检测报告（MinerU 未接入态）
9. #settings 全局设置

## 三、数据域（草案，M3 schema 定稿）
- 通用：报告（3）、指标值（3）、事件/用药/筛查/文档/随访（7）
- 病种专属（N 项候选）：发作事件、钙剂剂量、活性维生素 D 剂量、尿钙组、骨密度组、基因检测依据
- 导入：化验单照片/PDF、报告 PDF、文本粘贴（3 通道）
- 红线：无 diagnosis / risk_level / activity_score 类判定列；阈值一律【待核】占位，未过临床审核不得转正。

## 四、AI 能力边界
- AI 输出永远是「候选/预览」；演示态明说未接入。
- 派生值读时算不落库；私密三出口（看板/导出/AI 上下文）同一过滤函数。
