# INTERACTION-DESIGN · 交互路径全量（IP1，M1 版）

- 版本：v0.2 · 2026-11-14 · 本文档=28 号 IP1 交付；签认记录见 docs/signoffs/G1-自动签认.md。
- 页面树：10 一级 + 二级见下；每个 (view,sub) 至少被一条路径经过（IP2）。

## 一级/二级
dashboard / records[资料库, 整理草稿与核对, 确诊档案, 指标检测, 汇总] / labs[三联组, 尿钙与肾功能, 骨密度] / chart[数值曲线, 分类与事件, 数据口径] / meds[当前剂量, 变更链, 同轴对照] / events[发作泳道, 事件登记] / followups[筛查清单, 节奏与待办] / mind[当下感受, 家庭负担与照护者] / trial[建档, 检索, 匹配结果] / review[复诊准备, 资料与导出]

## 场景→路径（与 SCENARIOS 双向映射）
- P1（S1）：看板→「病情整理」→资料库→导入→候选核对→确认入档（产物：档案条目+1）→回看板。
- P2（S2）：看板→「化验与指标」→三联组→点卡翻面→「病情一图秀」→数值曲线（产物：可比组选中态）→回看板。
- P3（S3）：看板→「用药滴定」→当前剂量→「变更链」→登记变更（产物：变更条目；旧版本保留）→同轴对照→回看板。
- P4（S4）：看板→「发作与缓解」→事件登记→选类型/时间/处置原文→保存（产物：泳道事件+1）→发作泳道→回看板。
- P5（S5）：看板→「筛查与随访」→筛查清单→勾已完成/登记日期（产物：清单状态变化）→回看板。
- P6（S6）：看板→「资料与复诊」→复诊准备→生成速览→导出（产物：导出文件；私密过滤）→回看板。
- P7（S8）：看板→「临床试验」→建档→检索→匹配结果（产物：候选线索）→收藏→回看板。
- P8（S9）：看板→「心理与家庭」→当下感受→写一条（产物：记录+1，默认私密）→家庭负担→回看板。

## 硬规则（继承家族）
- 入口名=界面文案=导航 key 逐字一致（IP3）；每路径有产物+一步回首页（IP4）。
- 每个可写实体有 AI 候选通道（IP5）；显式编辑入口 ≤1，手工入口收「⋯ 更多」（IP6）；数字输入用数字键盘组件（IP7）；无裸删除，更正=新增版本（IP8）；手工/AI 同一事实层（IP9）；每页「和 AI 讨论」双入口（IP10/IP11）。
- 孤儿页穷举：M2 探针脚本输出（页面数/覆盖数/孤儿列表）。
