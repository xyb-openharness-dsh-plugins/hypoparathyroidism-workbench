## 推导的患者旅程与痛点（无引语，逐条待访谈验证）
1. **确诊期**：口周麻木/手足搐搦反复就诊→误诊（焦虑/癫痫）→住院查三联→基因检测。痛点：罕见+易误诊，确诊档案需要可携带可解释。
2. **滴定期**：每 2–4 周调药+化验（节奏【待核】）。痛点：「为什么加了钙还要查尿钙」——剂量变更与尿钙的先后关系说不清。
3. **稳定期**：3–6 月化验一次。痛点：换医院要重新解释病史；化验单数值分散。
4. **发作期**：漏服/腹泻/感染诱发急性低钙→急诊。痛点：急诊接待医生不熟本病，需要一页病史速览。
5. **随访期**：年度并发症筛查+生育遗传咨询。痛点：不知道查什么、多久查一次。
