# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：遗传性/术后甲状旁腺功能减退症患者及家属照护者；长期补钙补活性维生素D、需周期性化验者；低钙血症急性发作经历者；患者组织志愿者协作使用

场景：确诊依据档案（PTH/血钙血磷/基因检测/CaSR或GCM2等突变报告）与误诊经历留痕；钙-磷-PTH三联化验趋势与较上次读数；钙剂与活性维生素D剂量滴定与变更史；尿钙/肾功能/骨密度等并发症筛查节奏；急性低钙发作—缓解事件（口周麻木、手足搐搦、喉痉挛）；饮食与钙摄入；长期随访节律；默认私密的家庭记录

核心流程：
1. 选择本机资料目录并导入化验报告与出院小结
2. 核对候选信息，建立确诊依据档案与化验目录
3. 记录钙剂/活性维生素D剂量变更与低钙发作事件
4. 查看钙-磷-PTH趋势与并发症筛查节奏
5. 生成复诊材料并归档

完成结果：得到来源可追溯、可核对的个人病程档案：化验三元组趋势、用药剂量变更链、发作事件线、并发症筛查清单、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
